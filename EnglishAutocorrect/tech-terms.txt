# Technical vocabulary that is never autocorrected.
#
# These are words a developer types deliberately but that no general
# English dictionary carries, so every spell checker treats them as
# misspelled and reaches for the nearest real word -- "kubectl" becomes
# "tubercle", "redis" becomes "rides". Listing them here stops that.
#
# The list only *protects*: a term here is left exactly as typed. It is
# not a correction target, so a typo of one ("kubernets") is left alone
# rather than fixed.
#
# One term per line, case-insensitive. Blank lines and #-comments are
# ignored. Adding a term needs a rebuild; the Learned Words window is
# the way to add one instantly.
#
# Short terms that double as plausible typos of English words (env, sed,
# nvm) are included deliberately: for someone who types them daily, a
# wrong "correction" costs more than an uncaught slip.
